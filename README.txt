NUR HASNAT NISHAT — BIRTHDAY WEBSITE

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder in VS Code.
3. Open index.html in your browser.
   Recommended: use the VS Code Live Server extension and click "Go Live".

CUSTOMIZE
- Edit the birthday message in index.html.
- Replace assets/nishat-portrait.jpg if you want to use a different portrait.
- Change the date in index.html if needed.
- Colors and layout are in style.css.
- Interactions and animations are in script.js.

NOTES
- The site is mobile responsive.
- Sound is optional and starts only after the visitor taps Sound off.
- The sound is generated in the browser using Web Audio; no music file is required.
- Google Fonts need an internet connection; fallback fonts are included.
